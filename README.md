# Maven Cycles - Power BI Sales Dashboard
Type: Personal/Course
Tools: Power BI, Power Query, DAX

## Overview
Developed an interactive dashboard using the Maven Cycles dataset to analyze sales performance,
product trends, customer demographics, and geographic performance.

## Skills Demonstrated
- Data cleaning/transformation
- Data modeling
- DAX measures
- KPI development
- Interactive dash design
- Trend analysis
- Customer/product analysis

## Project Context
This project was completed as part of a PL-300 course review using the provided Maven Cycles dataset.
